# جماعت پنجم — 35 منٹ کا لیسن پلان

GPS 278 GB، مرکز روڈالہ کے لیے اردو انٹرفیس والی آف لائن ویب ایپ۔

## خصوصیات
- جماعت پنجم کے متعدد مضامین، بشمول English
- 35 منٹ یا منتخب دورانیے کی خودکار وقت تقسیم
- مقاصد، سابقہ معلومات، تدریسی معاونات، سرگرمیاں، جائزہ اور گھر کا کام
- A4 پرنٹ اور Print dialog کے ذریعے Save as PDF
- لیسن پلان کو TXT میں ڈاؤن لوڈ کرنا
- موبائل اور کمپیوٹر پر قابل استعمال
- کسی سرور یا API key کی ضرورت نہیں

## چلانے کا طریقہ
`index.html` فائل کو کسی بھی جدید براؤزر میں کھولیں۔

## GitHub Pages پر شائع کرنا
1. GitHub پر نئی repository بنائیں، مثلاً `grade5-lesson-planner`۔
2. اس فولڈر کی `index.html` اور `README.md` فائلیں اپ لوڈ کریں۔
3. Repository میں **Settings → Pages** کھولیں۔
4. **Deploy from a branch** منتخب کریں، branch `main` اور folder `/ (root)` رکھ کر Save کریں۔
5. GitHub Pages کی جانب سے دیے گئے URL سے ایپ کھولیں۔
